### 🧠 Background & Approach

With a strong foundation in **mathematics** (probability, statistics, linear algebra, and stochastic processes) combined with **software engineering** best practices, I focus on building deterministic, high-performance financial systems.

My work sits at the intersection of quantitative modeling and production-grade engineering:
- **Strictly Causal Research:** Developing backtesters and execution engines that rigorously prevent lookahead bias, enforce intra-bar execution discipline, and test for prefix-stability.
- **Robust Financial Infrastructure:** Architecting ETL pipelines and normalized database schemas for multi-exchange order flow, ETF flows, and global liquidity estimation.
- **Performant Visual Analytics:** Translating complex market microstructure and dispersion mechanics into intuitive, low-latency interfaces using modern reactive web frameworks.
